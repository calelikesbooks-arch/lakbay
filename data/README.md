# data/

Transport data lives here as plain files, so Git keeps its history.

- `sources/` – evidence: survey notes, LTFRB circulars, photo metadata
- `curated/` – master data you edit by hand (places, stops, routes, fare rules)
- `build/` – generated JSON for the app (never edit by hand)

Empty in Milestone 1. The data dictionary and first records come in Milestone 2.
No invented data: every route needs a cited source and a "last verified" date.
